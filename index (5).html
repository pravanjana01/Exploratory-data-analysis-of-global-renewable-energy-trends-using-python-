2. Abstract

Renewable energy plays an important role in reducing dependence on fossil fuels and supporting sustainable development. Solar, wind, hydroelectric, biomass and geothermal energy are important sources of renewable electricity and heat.

This project demonstrates Exploratory Data Analysis (EDA) techniques for studying renewable energy generation across countries and years. The project explains data collection, data cleaning, descriptive statistics, visualization and interpretation using Python libraries such as Pandas, NumPy, Matplotlib and Seaborn.

Bar charts, line charts, pie charts and correlation analysis can help identify patterns, compare energy sources and communicate results clearly. The analysis can support further investigation into clean energy development.

Keywords: Exploratory Data Analysis, Renewable Energy, Python, Pandas, Data Visualization, Sustainability.

3. Introduction

Exploratory Data Analysis is the process of examining a dataset before applying advanced statistical or machine learning methods. It helps us understand the structure of data, discover patterns, detect missing values and identify relationships between variables.

Renewable energy comes from sources that are naturally replenished. These sources include sunlight, wind, flowing water, organic materials and heat from within the Earth.

Why is this topic important?

  • Renewable energy is important for sustainable development.
  • Data analysis helps compare energy sources.
  • Historical data can reveal changes over time.
  • Visualizations make complex information easier to understand.
  • Data-driven findings can support better energy planning.

Role of Data Science

Data science combines programming, statistics and visualization to extract useful information from datasets. In this project, these techniques are applied to renewable energy data to demonstrate a practical application of EDA.

9. Data Cleaning

Data cleaning improves the quality and consistency of a dataset before analysis.

  • Inspect missing values in each column.
  • Identify exact duplicate records.
  • Convert numerical columns into numeric data types.
  • Check that year values are valid.
  • Check for negative or implausible energy values.
  • Keep track of any records removed or modified.
Missing values should not automatically be replaced with zero. A missing value may mean that information was unavailable, rather than that energy generation was zero.

10. Statistical Analysis

Mean

The mean is calculated by dividing the sum of all observations by the number of observations.

Mean = Sum of observations / Number of observations

Median

The median is the middle value after observations are arranged in order. It is useful when data contain extreme values.

Standard Deviation

Standard deviation describes how widely numerical values are spread around their mean.

Correlation

Correlation measures the strength and direction of a linear relationship between two numerical variables. Correlation does not by itself establish causation.

Grouping and Comparison

Grouping records by country, year or energy source helps compare generation patterns and identify areas for further study.

12. Python Program for EDA

The following program demonstrates how to load a CSV dataset, clean data, calculate statistics and generate visualizations.

Before running the program: Download a real dataset and prepare a CSV file with these columns: Country, Year, Solar_TWh, Wind_TWh, Hydro_TWh, Biomass_TWh and Geothermal_TWh. Save the file as global_renewable_energy.csv in the same working folder as the Python program. If the downloaded dataset has different column names, update the program accordingly. 
# Exploratory Data Analysis of Renewable Energy

# 1. Import required libraries
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns

# 2. Load the dataset
df = pd.read_csv("global_renewable_energy.csv")
# 3. Display basic information
print("First five records:")
print(df.head())

print("\nDataset shape:")
print(df.shape)

print("\nColumn information:")
df.info()

print("\nMissing values:")
print(df.isnull().sum())


# 4. Remove duplicate records
df = df.drop_duplicates().copy()


# 5. Convert columns to appropriate data types
df["Year"] = pd.to_numeric(
    df["Year"], errors="coerce"
)

energy_columns = [
    "Solar_TWh",
    "Wind_TWh",
    "Hydro_TWh",
    "Biomass_TWh",
    "Geothermal_TWh"
]

for col in energy_columns:
    df[col] = pd.to_numeric(
        df[col], errors="coerce"
    )


# 6. Remove records without essential fields
df = df.dropna(
    subset=["Country", "Year"]
).copy()


# 7. Display cleaned data information
print("\nCleaned dataset shape:")
print(df.shape)

print("\nMissing values after initial cleaning:")
print(df.isnull().sum())


# 8. Calculate descriptive statistics
print("\nDescriptive Statistics:")
print(df[energy_columns].describe())


# 9. Calculate mean and median
print("\nMean values:")
print(df[energy_columns].mean())

print("\nMedian values:")
print(df[energy_columns].median())


# 10. Compare energy sources
source_totals = df[energy_columns].sum()

print("\nTotal values by energy source:")
print(source_totals)

source_totals.plot(
    kind="bar",
    figsize=(9, 5),
    title="Renewable Energy Source Comparison"
)

plt.xlabel("Energy Source")
plt.ylabel("Sum of Recorded Values")
plt.tight_layout()
plt.show()


# 11. Compare countries
country_totals = df.groupby("Country")[
    energy_columns
].sum().sum(axis=1)

top_countries = country_totals.sort_values(
    ascending=False
).head(10)

print("\nCountries with highest recorded totals:")
print(top_countries)

top_countries.plot(
    kind="bar",
    figsize=(10, 5),
    title="Top Countries by Recorded Renewable Energy"
)

plt.xlabel("Country")
plt.ylabel("Sum of Recorded Values")
plt.tight_layout()
plt.show()


# 12. Study trends over time
yearly_totals = df.groupby("Year")[
    energy_columns
].sum()

yearly_totals.plot(
    kind="line",
    marker="o",
    figsize=(10, 5),
    title="Renewable Energy Trends Over Time"
)

plt.xlabel("Year")
plt.ylabel("Sum of Recorded Values")
plt.grid(True)
plt.tight_layout()
plt.show()


# 13. Correlation analysis
correlation = df[energy_columns].corr()

print("\nCorrelation matrix:")
print(correlation)

plt.figure(figsize=(8, 6))

sns.heatmap(
    correlation,
    annot=True,
    cmap="YlGnBu",
    fmt=".2f"
)

plt.title("Correlation Between Energy Sources")
plt.tight_layout()
plt.show()


# 14. Final summary
print("\nEDA completed successfully.")
print("Interpret results using the actual dataset.")
